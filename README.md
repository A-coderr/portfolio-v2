# Anzhelika Kostyuk — Portfolio

Production portfolio built with Next.js, TypeScript, React, Tailwind CSS, and React Three Fiber.

## Technical Overview

- Next.js + React + TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- Vitest + React Testing Library
- Vercel deployment

## Local Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm test
npm run lint
npm run build
```

## Deployment

Deployed on Vercel.

Final production domain:

```text
https://anzhelikakostyuk.vercel.app/
```
